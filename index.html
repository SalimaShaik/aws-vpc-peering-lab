AWS VPC Peering Lab

Private Network Connectivity Between Two Amazon VPCs

Project Overview

This project demonstrates how two separate Amazon Virtual Private Clouds (VPCs) can communicate using a VPC Peering connection. The design includes private subnets, EC2 instances, route tables, and security groups.

Cloud platform: Amazon Web Services (AWS)

Region planned: Mumbai (ap-south-1)

Project type: Cloud Networking

Key Learning Outcomes

  • Understanding VPCs and subnet CIDR ranges.
  • Configuring VPC Peering connections.
  • Updating route tables for private network communication.
  • Controlling access through security group rules.
  • Testing network connectivity and troubleshooting failures.
  • Cleaning up cloud resources to avoid unnecessary charges.

Conclusion

The planned lab demonstrates how VPC Peering can enable private communication between workloads in two VPCs without requiring public IP addresses on the application instances.

Actual AWS deployment and connectivity verification remain to be completed.
